Бүтэц (I.EEA709-тэй ижил)
- index.html — хичээлийн вэб (нэвтрэх, нүүр, хөтөлбөр, хуваарь, материал, 12 лекц, тест, бие даалт,
  бодлого, тооцооны стенд — 8 лабораторийн ажил, улирлын шалгалт, багшийн хэсэг)
- pdf/lec01–12.pdf — лекцүүд (PDF)
- docs/lec/EEA732_Lekts01–12.docx — лекцүүд (Word, томьёо Word тэгшитгэлээр)
- tts/ — лекцийг дуут уншлагаар унших өгөгдөл
- docs/ — хөтөлбөр, тест, бие даалт, лабораторийн заавар (Word/PDF)
- Code.gs — оноо хадгалах сервер (Google Apps Script)

Байршуулах (GitHub Pages)
1. GitHub дээр «IEEA732» нэртэй шинэ repository үүсгэнэ (Public).
2. Энэ хавтасны БҮХ файлыг repository-д хуулна.
3. Settings → Pages → Branch: main, / (root) → Save.
4. Хаяг: https://gantumur2020-spec.github.io/IEEA732/

Сервер (Google Sheets + Apps Script) — ШИНЭЭР үүсгэнэ
1. Google Sheets-д «I.EEA732 Дэд станцын орчин үеийн технологи — оноо» нэртэй шинэ хүснэгт үүсгэнэ.
2. Extensions → Apps Script → Code.gs-ийн агуулгыг хуулж тавина (SHEET_ID-д хүснэгтийн ID-г бичиж болно).
3. Project Settings → Script Properties → PW = багшийн нууц үг.
4. Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone) → /exec хаягийг хуулна.
5. index.html доторх  const API_URL = ""  мөрөнд /exec хаягийг бичнэ.
   API_URL хоосон үед вэб сервергүй горимд ажиллана (оноо зөвхөн хөтөч дотор хадгалагдана).
6. EEA732_Оюутан хуудсанд оюутны код, овог нэр, ангийг оруулна. Хувилбар (1–10) = жагсаалт дахь дараалал.

Үнэлгээ: Лекцийн тест 40 + Бие даалт (6 × 5) 30 + Улирлын шалгалт 30 = 100.
